# 词表数据外置架构说明（开源可见版 · 仅记数量与类别）

本项目把「来自私有语料治理实践的功能性词表条目」与开源代码解耦：

- **代码内**：只保留通用默认词表（行政通用词/常见姓氏/通用名用字/通用行业
  尾词等，约 2,270 条）——开源仓库开箱即用的完整功能形态；
- **外置档** `wordlists_private.json`（**不随开源仓库分发**，约 53 条）：
  品牌特例例外 1 / 名用字语料增补段 36 / 单姓增补 1 / 机构名碎片 5 /
  真名白名单 1 / 家居行业形状词 10——这些条目源自真实语料的治理迭代，
  属于原使用方的私有运营数据。

加载链（与 brands.json 同构）：环境变量 `FINMASK_WORDLISTS` → 程序目录
`wordlists_private.json` → 缺省（空，同时发出一条醒目警告防止静默降级）。

**对开源用户的意义**：不配置外置档时，引擎按通用词表运行（本文档所称
「开源默认态」）；如需复现带私有治理条目的行为，可自行构造同 schema 的
外置档（键契约见 `app/wordlists_private.py` 模块文档字符串）。

## 回归口径（贡献者须知）

- 带/不带外置档是两种**确定的行为形态**，各有独立基线（见
  docs/templates/test_log_template.md 的记录法）；
- 修改任何词表时须双向双跑验证（带档对带档、空档对空档）；
- 外置档不入库——涉及它的测试须在档缺失时优雅跳过（仓库测试已按此
  模式配置，参考 tests/conftest.py）。
